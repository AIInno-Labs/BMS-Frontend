# FRP Engineering — Fabrication Jobs Prototype

Enterprise-grade demo for **FRP Engineering** (fibre reinforced plastic: gratings, handrails, walkways).

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Features

- **Dashboard** — Ready to Manufacture pie chart + scheduling whiteboard modal
- **Jobs** — Whiteboard-aligned table, resin/client filters, pipeline chart
- **Job card** — Editable traveler card with `window.print()` PDF export

## Stack

Next.js 15 · Tailwind CSS 4 · Lucide React · Recharts
